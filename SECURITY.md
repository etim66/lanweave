# Security Policy

Lanweave is incomplete, unaudited, and not currently suitable for sensitive
files. See [`docs/SECURITY.md`](docs/SECURITY.md) and
[`docs/CRYPTOGRAPHY.md`](docs/CRYPTOGRAPHY.md) for the current security design,
known limitations, and release gates.

Please report potential vulnerabilities privately through the repository's
GitHub security advisory feature. Do not include secrets, private file paths, or
sensitive transferred data in a public issue.
